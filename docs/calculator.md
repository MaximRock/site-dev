# Калькулятор стоимости — шпаргалка настройки

Калькулятор реализован в `src/components/Calculator.astro` и подключён на главной
(`src/pages/index.astro`). Настраиваются данные и тексты — структура менять не нужно.

## Где что лежит

- `src/components/Calculator.astro` — логика и данные в блоке `<script>`.
  HTML-шаблон статичен, JS рендерит вопросы динамически.
- `src/pages/index.astro` — подключение компонента (`<Calculator />`).
- `src/styles/global.css` — стили: `.option` (кнопки), `.chip` (теги в итоге),
  `.card`, `.btn-*` (кнопки навигации).

## Модель данных

Калькулятор работает в двух фазах:

1. **Выбор типа** (.phase 1) — кнопка `TYPE_PICKER` с тремя вариантами
   (Лендинг / Многостраничный / Сайт-визитка).
2. **Вопросы по типу** (phase 2) — массив `TYPE_STEPS[type]` содержит
  _steps именно для этого типа. Общие вопросы (платформа, дизайн, контент,
   интеграции, домен, сроки) определены один раз и включены во все типы.

### Формула цены

```
price = BASE[type] × PLATFORM_COEF[platform] + сумма_допов, × 1.3 при срочности, округление до 1000
```

## Чек-лист настройки

### Цены

- **Базовые цены по типу** — `BASE` (lines 229–233). Значения в числах:
  `landing: 15000`, `multipage: 25000`, `visitka: 10000`.
- **Коэффициент платформы** — `PLATFORM_COEF` (lines 235–238):
  `platform_code: 1`, `platform_tilda: 0.8`.

### Допы (add-ons) — `computePrice()` (lines 240–263)

### Вопросы и варианты

Общие шаги (определены один раз, используются во всех типах):

| Переменная | id | Вопрос |
|-----------|-----|--------|
| `stepPlatform` | `platform` | Как реализуем сайт? |
| `stepDesign` | `design` | Что с дизайном? |
| `stepContent` | `content` | Кто готовит тексты и фото? |
| `stepIntegrations` | `integrations` | Нужны ли интеграции? |
| `stepDomain` | `domain` | Домен и хостинг есть? |
| `stepTerms` | `terms` | Какие сроки? |

Типо-специфичные шаги:

| Тип | Дополнительные шаги |
|----|---------------------|
| `landing` | `stepBlocks` (блоки), `stepLeads` (заявки) |
| `visitka` | `stepPagesVisitka` (страницы), `stepLeadsVisitka` (заявки) |
| `multipage` | `stepPagesMp` (страницы), `stepStructure` (структура), `stepFunc` (функционал) |

Порядок шагов внутри типа задаётся в `TYPE_STEPS` (lines 173–177).

### Названия типов и подписи

- **Типы** — `TYPES` (lines 189–193): отображаются в заголовке результата.
- **Подписи значений** — `VALUE_LABELS` (lines 195–227): каждый `value`
  должен иметь читаемую подпись, иначе в итоге покажется сырой ключ.
- **Заголовок секции** — тексты в HTML (lines 4–6).

## Как менять вопросы

1. Найти нужный шаг (`stepXxx`) и изменить `options` — добавить/удалить/переименовать.
2. Добавить новый `value` в `VALUE_LABELS`, чтобы он отображался в итоге.
3. Если вопрос специфичен для типа — создать новый шаг и включить его в `TYPE_STEPS[type]`.
4. Если вопрос универсальный — использовать/добавить общий шаг (сейчас 6 штук).

## Как менять цены

1. Базовые цены — менять значения в `BASE`.
2. Коэффициент платформы — менять в `PLATFORM_COEF`.
3. Допы — менять числа в `computePrice()` (секция if/if/if).
4. Круглое округление: `Math.round(price / 1000) * 1000`.

## Как проверить

1. `astro build` — проверить, что нет ошибок компиляции.
2. `astro dev --background`, открыть `#calculator` на главной.
3. Пройти все три типа (Лендинг / Многостраничный / Визитка).
4. Проверить: прогресс-бар меняется, кнопка «Назад» работает,
   кнопка «Показать стоимость» появляется на последнем шаге.
5. Проверить расчёт: базовая цена + допы, срочность ×1.3, округление.
6. Проверить кнопку «Рассчитать снова» — сброс к выбору типа.
