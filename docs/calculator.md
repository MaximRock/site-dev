# Калькулятор стоимости — шпаргалка настройки

Калькулятор уже реализован и подключён на главной странице
(`src/components/Calculator.astro`, секция `#calculator`). Настраиваются только
данные и тексты — структуру менять не нужно.

## Где что лежит

- `src/components/Calculator.astro` — вся логика и данные в блоке `<script>`.
- `src/pages/index.astro:29` — подключение компонента (`<Calculator />`).
- `src/styles/global.css` — стили: `.option` (кнопки), `.chip` (итоговые теги),
  `.card`, `.btn-*` (кнопки навигации).

## Чек-лист настройки

- [ ] **Цены по типу сайта** — объект `PRICES` (`Calculator.astro:97-102`).
      Формат: `"landing": "от 15 000 ₽"`.
- [ ] **Названия типов** — объект `TYPES` (`Calculator.astro:104-109`),
      используется в итоговом заголовке.
- [ ] **Вопросы и варианты** — массив `steps` (`Calculator.astro:47-95`).
      Каждый шаг: `{ title, options: [{ value, label }] }`.
      `value` — внутренний ключ, `label` — что видит клиент.
- [ ] **Подписи для итога** — объект `ANSWERS` (`Calculator.astro:111-123`).
      Для каждого нового `value` добавить строку, иначе в итоге покажется сырой ключ.
- [ ] **Заголовок секции** — тексты `<p>/<h2>/<p>` (`Calculator.astro:4-6`).
- [ ] **Текст под результатом** — `Calculator.astro:34-37` (пояснение, что
      считается только по типу сайта).
- [ ] **Валюта** — сверить с `data-for.md` (там «тр» = тысячи ₽, в коде «₽»).
      Решить, что корректно, и привести к одному виду.

## Как менять вопросы

1. В `steps` добавить/удалить объект с `title` и `options`.
2. Порядок в массиве = порядок шагов (счётчик «N из 6» берётся из длины).
3. Добавить каждый `value` в `ANSWERS`, чтобы он читабельно отображался в итоге.

## Как менять цены

- Цена сейчас зависит ТОЛЬКО от ответа на первый вопрос (`showResult`,
  `Calculator.astro:175-198`, берёт `answers["0"]`).
- Чтобы цена считалась по всем ответам (страницы, магазин, CRM) — нужна
  отдельная доработка формулы в `showResult`.

## Как проверить

- `astro dev --background`, открыть `#calculator` на главной.
- Пройти все шаги, проверить прогресс-бар, итог и кнопку «Получить точный расчёт».
- `astro dev logs` — если скрипт упал.
