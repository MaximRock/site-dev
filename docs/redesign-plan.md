# План реконструкции сайта

Дата: 26 октября 2026

## Задача

Сократить перегруженную главную страницу. Сейчас в ней 21 смысловой блок, многие повторяют одну и ту же мысль. Нужно оставить понятный путь: работа, форматы, процесс, доверие, ответы на вопросы, заявка.

## Главная проблема

- Три блока подряд зовут подписаться на каналы.
- Два блока рассказывают про ошибки на сайте.
- Три блока объясняют, как мы работаем.
- Два блока отвечают на вопрос «какой сайт нужен».
- Два блока говорят про цену.
- Три блока заканчиваются бесплатным разбором.

Из-за повторов страница длинная, а главная мысль теряется.

## Решение

Было 21, станет 9 блоков: 8 смысловых и подвал.

Калькулятор убираем полностью. Расчёт стоимости остаётся в блоке форматов и цен.

## Что делаем с текущими блоками

| Сейчас | Решение |
| --- | --- |
| Первый экран | Оставить. Один призыв и три коротких факта. |
| «Не готовы заказывать? Посмотрите каналы» | Убрать. Это преждевременный призыв. |
| «Возможно, вам не нужен новый сайт» | Убрать как отдельный блок. Главные мысли перенести в чек-лист и FAQ. |
| «Мы начинаем не с дизайна, а с задачи» | Убрать как отдельный блок. Одна фраза внутри «Как мы работаем». |
| «Какой сайт нужен бизнесу» | Объединить с технологиями и ценой в один блок «Форматы и цены». |
| «Tilda или индивидуальная разработка» | Объединить с форматами. Отдельное сравнение не нужно. |
| Калькулятор | Убрать полностью. |
| Кейсы | Оставить и поднять выше. Показать 3 сильных кейса вместо 8 одинаковых. |
| «Хотите видеть процесс в каналах» | Убрать. |
| «Почему не нужен дорогой сайт» | Объединить с форматами и ценами. |
| «Почему с нами удобно» | Сократить до 3 фактов и перенести в блок доверия. |
| Команда | Оставить двух человек внутри блока доверия. |
| «Шесть шагов» | Оставить 4-5 шагов. |
| «Посмотрите нашу работу» | Убрать. |
| «Что входит в разработку» | Убрать 12 плиток. Оставить 5-6 главных пунктов внутри процесса. |
| «7 ошибок» | Оставить один чек-лист. Сократить до 5 ошибок. |
| «Бесплатная диагностика» | Убрать отдельный блок. Обещание перенести в финальный призыв. |
| Отзыв | Оставить один отзыв внутри кейсов или блока доверия. |
| FAQ | Оставить 6 вопросов. |
| Финальный призыв | Объединить с формой. |
| Форма | Оставить 3 поля и одну кнопку. |
| Подвал | Оставить, немного упростить. |

Один блок со ссылками на каналы можно оставить маленькой строкой после кейсов или в подвале. Отдельные секции для этого не нужны.

## Новая структура

1. Первый экран.
2. Кейсы и один отзыв.
3. Форматы сайтов и цены.
4. Как мы работаем и что входит.
5. Почему нам можно доверять: 3 факта и команда.
6. Чек-лист.
7. FAQ.
8. Финальный призыв с формой.
9. Подвал.

## Порядок работы

1. Собрать новый каркас страницы из 9 блоков.
2. Перенести тексты и ссылки из старых блоков.
3. Переписать повторяющиеся места, чтобы каждая мысль встречалась один раз.
4. Убрать калькулятор и его стили.
5. Проверить мобильную версию, доступность и обе темы.
6. Сделать скриншоты и проверить страницу вручную.

## Что не делаем

- Не добавляем калькулятор обратно.
- Не оставляем отдельные блоки про каналы, преимущества, команду и отзывы.
- Не дублируем бесплатный разбор в трёх местах.
- Не выбрасываем полезный текст, а переносим его в подходящий блок.
