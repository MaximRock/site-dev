# Калькулятор — вопросы по типам сайтов

> Статусы: **Лендинг ✅ финализирован**, **Визитка ✅ финализирована**, **Многостраничный ✅ финализирован**.
> Цены и допы — см. `docs/calculator-prices.md`.
> Настройка компонента — см. `docs/calculator.md`.
>
> Дизайн / контент / интеграции / домен / сроки, а также платформа (Tilda или код) — общие для всех типов.
> Ключи значений (`platform_*`, `design_*`, `content_*`, `integrations_*`, `domain_*`, `terms_*`) едины;
> при реализации в коде описываются один раз и переиспользуются ветвлениями — без дублирования.
> Tilda — не отдельный тип, а вариант платформы в общем вопросе 2.

## Шаг 0 — тип сайта (общий)

Лендинг / Многостраничный сайт / Сайт-визитка.

> Интернет-магазин — тип отложен. Вернёмся, когда будут расценки и понятный процесс работы с корзиной/оплатой.

## Лендинг · ✅ финализирован (8 вопросов)

### 1. Сколько экранов (блоков) будет на странице?

| Вариант | Сложность |
|---|---|
| До 6 — базовый набор: герой, услуги, о нас, контакты | |
| 7–10 — + отзывы, кейсы, FAQ | ↑ |
| Больше 10 — большой продающий лендинг | ↑↑ |

*Зачем спрашивать: главный фактор трудоёмкости дизайна и вёрстки.*

> Будущее значение: `blocks_few` / `blocks_mid` / `blocks_many`

### 2. Как реализуем сайт?

| Вариант | Сложность |
|---|---|
| На конструкторе Tilda — быстрее и бюджетнее | |
| Кодом с нуля — полная свобода по дизайну и функциям | ↑ |

*Зачем: влияет на трудоёмкость; если выбран Tilda — уточнить наличие подписки (Personal/Business).*

> Будущее значение: `platform_tilda` / `platform_code`

### 3. Как собираете заявки?

| Вариант | Сложность |
|---|---|
| Обычная форма (имя + телефон) | |
| Форма + квиз-опрос | ↑ |
| Интерактивный калькулятор цены на странице | ↑↑ |

*Зачем: форма — чистая вёрстка; квиз / калькулятор — JS-разработка сверху.*

> Будущее значение: `form` / `quiz` / `calc`

### 4. Что с дизайном?

| Вариант | Сложность |
|---|---|
| Фирстиль есть (логотип, цвета) | |
| Нужен дизайн под ключ — палитра, шрифты, отрисовка макета | ↑ |

*Зачем: дизайн под ключ — отдельная фаза работы, +7 000 ₽.*

> Будущее значение: `design_ready` / `design_custom`

### 5. Кто готовит тексты и фотографии?

| Вариант | Сложность |
|---|---|
| Всё есть | |
| Частично — тексты наши, фото подбираем мы | ↑ |
| Под ключ — копирайтинг + подбор фото | ↑↑ |

*Зачем: контент — копирайтинг от 1 000 ₽/страница, подбор фото — от 800 ₽/страница.*

> Будущее значение: `content_full` / `content_partial` / `content_none`

### 6. Нужны ли интеграции?

| Вариант | Сложность |
|---|---|
| Не нужны | |
| Аналитика (Метрика) + кнопки мессенджеров | ↑ |
| Плюс автоподача заявок в CRM (Битрикс24/amoCRM) | ↑↑ |

*Зачем: интеграция CRM — +4 000 ₽; аналитика + мессенджеры — лёгкая доработка.*

> Будущее значение: `integrations_no` / `integrations_basic` / `integrations_crm`

### 7. Домен и хостинг есть?

| Вариант | Сложность |
|---|---|
| Есть, свой | |
| Нужно подобрать и подключить за нас | ↑ |

*Зачем: если клиент не разобрался — это дополнительная работа по настройке.*

> Будущее значение: `domain_no` / `domain_yes`

### 8. Какие сроки?

| Вариант | Сложность |
|---|---|
| Срочно (1–2 недели) | ↑ ×1,3 |
| Стандартно (3–4 недели) | |
| Не горит | |

*Зачем: срочность = надбавка ×1,3.*

> Будущее значение: `terms_urgent` / `terms_standard` / `terms_flexible`
