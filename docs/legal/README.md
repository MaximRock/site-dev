# Юридические документы

Исходные `.docx` — канонические версии документов. Страницы сайта содержат
опубликованный текст и должны совпадать с исходником.

| Документ | Страница сайта | Исходник | Дата |
| --- | --- | --- | --- |
| Политика обработки персональных данных | `/privacy` | `personal-data-policy-2026-11-13.docx` | 13 ноября 2026 |
| Политика использования cookie-файлов | `/cookies` | `cookie-policy-2026-11-12.docx` | 12 ноября 2026 |

## Порядок обновления

1. Новая редакция сохраняется отдельным файлом с датой в имени, старый файл не
   перезаписывается.
2. Текст переносится на соответствующую страницу без изменения формулировок,
   дат, контактов и ссылок.
3. В таблицу выше добавляется актуальная редакция.
4. Перед публикацией выполняется сборка и проверка страниц.

Файлы из этого каталога не публикуются на сайте: `docs/` не входит в сборку.
