# Калькулятор стоимости — план цен и вопросов

> Спецификация контента для калькулятора (`src/components/Calculator.astro`).
> Цена рассчитывается по формуле на основе ответов пользователя.
> Настройка самого компонента — см. `docs/calculator.md`.

## 1. Базовые цены по типам сайта

| Тип | База (код ×1) | Tilda (×0,8) |
|---|---|---|
| Лендинг | 15 000 ₽ | 12 000 ₽ |
| Многостраничный сайт | 25 000 ₽ | 20 000 ₽ |
| Сайт-визитка | 10 000 ₽ | 8 000 ₽ |

> Интернет-магазин — тип отложен. Вернёмся, когда будут расценки и понятный процесс работы с корзиной/оплатой.

> Подписка Tilda (Personal ~590 ₽/мес) оплачивается клиентом отдельно — не входит в разработку.

### Формула

```
price = BASE[type] × PLATFORM_COEF[platform] + сумма_допов, затем ×1.3 если срочно, округление до 1000
```

Реализация: `computePrice()` в `Calculator.astro:240–263`.

## 4. Реализация в коде

- Ветвление по типу: `TYPE_STEPS` задаёт массив шагов для каждого типа.
- Общие вопросы определены один раз (platform, design, content, integrations, domain, terms).
- Подписи значений — `VALUE_LABELS`, формула — `computePrice()`.
- Цены — `BASE`, коэффициент платформы — `PLATFORM_COEF`.
