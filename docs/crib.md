# Crib — шпаргалка по проекту

## Сервер разработки

| Команда | Описание |
|---|---|
| `npm run dev` | Запуск dev-сервера на дефолтном порту 4321 |
| `npm run dev -- --port 4322` | Dev-сервер на порту 4322 (через npm script) |
| `astro dev --port 4322` | Dev-сервер на порту 4322 (напрямую через astro CLI) |
| `astro dev --port 4322 --background` | То же, но в фоновом режиме |
| `astro dev stop` | Остановка фонового dev-сервера |
| `astro dev status` | Проверить статус фонового сервера |
| `astro dev logs` | Логи фонового сервера |

> **Почему порт 4322:** если на 4321 уже висит процесс, Astro автоматически берёт следующий свободный порт. Чтобы избежать путаницы, запускайте явно на `--port 4322`.

## Сборка и превью

| Команда | Описание |
|---|---|
| `npm run build` | Production-сборка в `dist/` |
| `npm run preview` | Локальный preview собранного сайта |

## Картинки в блоке «Наши проекты»

Превью проектов хранятся в `public/cases/` и подключаются через поле `image` в массиве `CASES` (`src/data/site.ts`).

### Формат файлов

Любой формат, который поддерживает `<img>`: **PNG**, **WebP**, **JPG**, **SVG**.
Рекомендуемое соотношение сторон — ~16:10 (например, 800×500).

### Заменить демо-заглушку на реальный скриншот

1. Положите файл в `public/cases/` (например, `mebel.webp`).
2. В `src/data/site.ts` найдите нужную запись в `CASES` и измените путь:
   ```ts
   image: "/cases/mebel.webp",   // было "/cases/mebel.svg"
   ```
3. `astro build` — проверить, что ошибок нет.

### Добавить новый проект

1. Положите картинку в `public/cases/`.
2. В `src/data/site.ts` добавьте запись в `CASES`:
   ```ts
   {
     title: "Название проекта",
     niche: "Ниша",
     type: "Тип сайта",
     image: "/cases/имя-файла.webp",
     works: ["Что сделали 1", "Что сделали 2"],
     task: "Задача клиента",
     result: "Результат",
     review: "Отзыв клиента",
     author: "Имя, должность",
   },
   ```

### Структура файлов

```
public/cases/
├── mebel.svg      ← студия мебели
├── service.svg    ← сервисная компания
└── school.svg     ← онлайн-школа
```
