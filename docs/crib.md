# Crib — шпаргалка по проекту

## Сервер разработки

| Команда | Описание |
|---|---|
| `npm run dev` | Запуск dev-сервера на дефолтном порту 4321 |
| `npm run dev -- --port 4322` | Dev-сервер на порту 4322 (через npm script) |
| `astro dev --port 4322` | Dev-сервер на порту 4322 (напрямую через astro CLI) |
| `astro dev --port 4322 --background` | То же, но в фоновом режиме |
| `astro dev stop` | Остановка фонового dev-сервера |
| `astro dev status` | Проверить статус фонового сервера |
| `astro dev logs` | Логи фонового сервера |

> **Почему порт 4322:** если на 4321 уже висит процесс, Astro автоматически берёт следующий свободный порт. Чтобы избежать путаницы, запускайте явно на `--port 4322`.

## Сборка и превью

| Команда | Описание |
|---|---|
| `npm run build` | Production-сборка в `dist/` |
