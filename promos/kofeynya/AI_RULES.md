# AI_RULES.md — форточка (для Dyad)

> Этот проект — уже готовый сайт. Не пересоздавать с нуля, не переносить на React / Next.js / Vite. Работать только внутри текущей структуры.

## Что это

Демо-витрина веб-студии: выдуманная кофейня «форточка». Статика, русский язык, всё вымышлено.
Стек: **Astro 7 (SSG) + TypeScript strict + Tailwind CSS v4 (CSS-first)**. SSR, тестов и линта нет.

## Команды

- `npm run dev` — локальный сервер (его запускает Dyad для preview)
- `npm run build` — проверка: собирается без ошибок, 2 страницы (`/`, `404`)
- Node `>=22.12.0`. Новые зависимости не ставить без спроса.

## Архитектура (не ломать)

- Весь русский текст, цены, часы, адреса — только в `src/data/cafe.ts` и `src/data/menu.ts`. В компонентах тексты не хардкодить, только props.
- `src/pages/index.astro` — только порядок 11 секций и проброс props. Логики и текстов там нет.
- `Menu.astro` — единственный компонент с `.map()` (рендерит `MenuItem`). Остальные секции — статичная раскладка по props.
- Новые файлы-компоненты не создавать без необходимости. Никаких `SectionHeading`, `Stamp`, карточек, слайдеров, CTA-баннеров.
- Скрипты только в `src/layouts/Layout.astro` (reveal-observer + параллакс). Дубли не создавать.

## Стили (Tailwind v4, токены — только в `src/styles/global.css`)

- Цвета/шрифты через `@theme`: `paper / ink / pine / lingonberry / pencil / pencil-ink`. Новые токены — только туда.
- Мелкий текст (подписи, сноски, расписание) — только `pencil-ink #676B67`. `pencil` — лишь линии и dotted-лидеры, не текст.
- Запрещены: тени, градиенты, скругления >2px, коричневые заливки. `lingonberry` — только акцент, ≤10% экрана.
- Фокус везде: `outline: 2px solid lingonberry`. Сохранять `lang="ru"`, один `h1`, skip-link.
- Сетка: 12 колонок / gap 24 / max-width 1200 / поля 24 (моб. 16). Один брейкпоинт — 768px. Full-bleed фото через `-mx-6`, никогда `100vw`.

## Изображения

- Финал — `public/images/` (9 `.webp`, kebab-case). Папку `image/_archive/` не трогать (тяжёлые исходники вне сборки).
- `hero.webp` — единственный `eager + fetchpriority="high"`. Остальные — `loading="lazy"` + обязательные `width/height` + русский `alt`.
- Подписи — моноширинным под фото, не поверх. Единственный overlap — штамп на булке.

## Motion

- Скрытые состояния `.reveal` / `.reveal-img` — только под классом `.js` (без JS сайт целиком виден).
- Параллакс — только `street.webp` через `[data-parallax]`, ±16px, выключен на тач и при `prefers-reduced-motion`. Новый параллакс не добавлять.
- Анимации 150–250мс `ease-out`, появление — сдвиг 8px + fade, один раз. Якорный скролл — нативный, без JS.

## Легенда (обязательно сохранять)

Россия без города, всё вымышлено. Адрес — `ул. Примерная, 1` + пометка «адрес вымышлен», телефон `+7`, цены в ₽, дисклеймер в футере обязателен.

## Как предлагать изменения

- Одно изменение за раз, маленькими шагами. Сначала объясни, что и почему меняешь (цвет, отступ, шрифт).
- Перед редизайном секции прочитай `docs/DESIGN_SYSTEM.md` (токены, ритм) и `docs/component-architecture.md` (таблица секций).
- После изменений: `npm run build` должен проходить; сверяйся с `docs/QA.md`.
